Discount Mart Sales Dashboard (Tableau)
###  📌 Project Overview

This project presents an end-to-end Tableau dashboard built to analyze sales performance for Discount Mart.
The dashboard helps stakeholders quickly understand sales, profit, quantity, trends, and geographic performance.

### 🎯 Objectives

Analyze overall sales, quantity, and profit

Identify top-performing categories

Track monthly sales trends

Understand sales distribution across states

Analyze quantity patterns using bins

🧩 Dashboard Components
🔹 KPI Cards

Total Sales: $2,297,201

Total Quantity Sold: 37,873

Total Profit: $689K

These cards give a quick business snapshot for decision-makers.

### 🔹 Sales by Category

Categories: Technology, Furniture, Office Supplies

Technology shows the highest sales contribution.

### 🔹 Monthly Sales Trend (2019)

Line chart showing month-wise sales

Includes average sales reference line

Helps identify seasonal trends and peak months

### 🔹 Quantity Distribution

Histogram with bins of size 2

Shows that most orders fall between 2–4 items

Useful for inventory and demand analysis

### 🔹 Sales by State (Map)

Interactive US map

Highlights high-performing states like California and Texas

Helps identify regional sales strength

### 🛠 Tools & Technologies

Tableau Desktop

Tableau Public

Data Sources: Excel / Structured Sales Dataset

### 📂 Filters & Interactivity

Category Filter

Order Year Filter

Interactive tooltips and selections

These features allow users to drill down into specific insights.

### 📈 Business Value

Enables fast, data-driven decision making

Acts as a single source of truth

Reduces dependency on long reports and raw data

Improves visibility into sales performance and trends

### 🚀 How to Use

Open the dashboard in Tableau Desktop or Tableau Public

Use filters to explore categories or time periods

Hover over visuals to view detailed insights
